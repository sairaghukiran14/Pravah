I spent the last few weeks building something I'm genuinely
excited about. 🔀

Meet HasaFlow — a visual AI pipeline studio for Indic languages.

The problem is simple: building a multilingual voicebot or
document processor for Indian languages means chaining
Speech-to-Text, Translation, LLM reasoning, and Text-to-Speech
together. Doing this in code means days of API plumbing, retry
logic, and latency debugging.

HasaFlow turns all of that into a drag-and-drop canvas.

Each node is an AI capability. Each edge is a live data stream.
You design your pipeline visually, hit Run, and watch it execute
node-by-node in real time.

📄 Document AI — OCR & document digitization

→ Voice call (Hindi) → Transcribe → Translate to English → Summary
→ Patient audio (Tamil) → Medical transcription → Clinical report
→ Hinglish query → Code-mix cleaning → LLM response → Voice reply

The tech stack:
• Next.js 16 + React 19
• React Flow (visual DAG editor)
• Topological execution engine
• Neon PostgreSQL + Prisma ORM
• Cloudflare R2 for audio storage

I'd love your feedback — what pipelines would you build?

Critical Rules

🚫
Do NOT put external links (GitHub, demo URL, YouTube) in the main post body. LinkedIn's algorithm aggressively suppresses posts with outbound links. Always use the first comment.
🚫
Do NOT tag more than 3–4 people. Over-tagging looks spammy and can trigger LinkedIn's spam filters, reducing your reach dramatically.
🚫
Do NOT publish and disappear. The first 90 minutes of engagement velocity are everything. If you don't reply to comments, the algorithm deprioritizes your post.
🚫
Do NOT send a desperate or overly long DM to Sarvam's team. Keep it professional, concise, and genuine. One short paragraph + links.
